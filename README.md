# F1 Race Strategy Command Board & Tactics Simulator

An advanced, real-time race strategy simulation dashboard built with Streamlit, Plotly, and Pandas. This platform models non-linear tyre degradation profiles, fuel mass progression, and dynamic weather matrices to calculate optimal multi-stop strategy options.

## Project Documentation
The complete, comprehensive research engineering reports, case studies, and exact mathematical models are compiled in full versions. 
Please find and download them from the file exchange list above to view all calibrated charts.

## How to Run the Simulator Locally
Ensure you have Python 3.9+ installed, then run the following commands in your terminal:
```bash
pip install streamlit pandas plotly
python -m streamlit run app.py
```
